## 🚀 Projets phares

### 🤖 [local-ai-homelab](https://github.com/Weebaay/local-ai-homelab)
Déploiement d'un **serveur IA local et privé** sur VM Ubuntu Server 24.04 sous VMware.
- Administration 100% en SSH depuis Windows (zéro interface graphique)
- Installation et configuration d'**Ollama** comme service **systemd**
- Exposition de l'**API REST** sur le réseau local (port 11434)
- Interface **Open WebUI** connectée au modèle Qwen2.5 7B
- Configuration réseau IP fixe via netplan

**Compétences :** Linux CLI · SSH · systemd · netplan · API REST · VMware

---

### 🏢 [CreativeFusion Studios — Infrastructure](https://github.com/Weebaay/lab-infrastructure)
Lab TSSR simulant une **infrastructure d'entreprise complète** pour une société fictive.
- **Active Directory** sur Windows Server 2022 (OU, GPO, utilisateurs, groupes)
- **DHCP** multi-scopes avec réservations
- **Routage inter-VLAN** via dot1Q sur Cisco Packet Tracer
- **GLPI** sur Debian 12 headless connecté à l'AD via **LDAP**
- Script **PowerShell déployé par GPO**
- Documentation GitHub structurée + article LinkedIn

**Compétences :** Windows Server · AD DS · DHCP · Cisco IOS · GLPI · LDAP · PowerShell
